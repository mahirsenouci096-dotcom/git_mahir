# Matrice RACI - Coordination du Projet ResourceHub

## Description des rôles
| Rôle | Description |
|------|-------------|
| **Vous (Étudiant)** | Chef de projet, propriétaire du projet, valide les orientations |
| **Agent (IA)** | Assistant technique, développement et implémentation, documentation |
| **Professeur** | Vérificateur, validateur, garant de la qualité et des critères d'acceptation |

---

| Tâche/Activité | Vous (Étudiant) | Agent (IA) | Professeur |
|---|---|---|---|
| **Définition & Conception** |
| Définir les spécifications fonctionnelles | **A** | C | C |
| Valider la fiche d'identité du projet | **A** | R | C |
| Concevoir l'architecture générale | **C** | **R** | C |
| Valider les choix techniques | **A** | C | C |

| Implémenter les fonctionnalités | I | **R** | I |
| Coder les modules | I | **R** | I |

| Vérifier les bonnes pratiques de code | **A** | C | **C** |
| **Tests & Qualité** |
| Définir les critères de test | **A** | C | C |

| Rédiger la documentation technique | I | **R** | C |
| Valider la documentation | **A** | C | **C** |

---

## Légende
- **R = Responsible (Responsable)** : Qui effectue le travail ou l'action
- **A = Accountable (Autorité)** : Qui rend des comptes et prend la décision finale
- **C = Consulted (Consulté)** : Qui donne des avis et des suggestions
- **I = Informed (Informé)** : Qui reçoit des mises à jour et des rapports

---

## Principes de coordination

1. **Points de synchronisation hebdomadaires**
   - Vous : Faire le point sur les avancées
   - Agent : Rapport sur les tâches accomplies et les blocages
   - Professeur : Retours et validations

2. **Validation progressive**
   - Chaque livrable intermédiaire doit être approuvé par vous et vérifiée par le professeur

3. **Documentation continue**
   - L'Agent produit la documentation
   - Vous validez que c'est conforme à la vision
   - Le Professeur évalue la qualité

4. **Escalade des décisions**
   - Les décisions stratégiques vous reviennent
   - Les décisions techniques peuvent être prises conjointement (Vous + Agent)
   - Le Professeur a le dernier mot sur la conformité aux critères
